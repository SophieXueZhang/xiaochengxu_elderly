# 视频分享功能使用指南

## 功能说明

用户可以在聊天页面分享练歌、跳舞等生活视频，AI陪伴角色会给予温暖的回应和鼓励。

## 如何使用

### 1. 进入聊天页面

点击"我的陪伴"页面中的任意陪伴角色，进入聊天页面。

### 2. 选择视频

点击输入框左侧的 **📹 视频按钮**，会弹出选择框：
- **从相册选择**：选择手机相册中的视频
- **拍摄视频**：现场录制新视频

### 3. 预览确认

选择视频后，系统会显示：
```
确认发送视频？
时长：45秒
大小：8.5MB

[取消] [发送]
```

### 4. 添加说明（可选）

点击"发送"后，可以选择是否添加文字说明：
```
添加说明
要为这个视频添加文字说明吗？

[直接发送] [添加]
```

如果选择"添加"，可以输入：
- "今天跳舞的视频"
- "练歌录音"
- "散步时的风景"
等文字描述。

### 5. 等待AI回应

视频上传后，AI陪伴角色会根据您的描述给予温暖的回应：

**示例1：跳舞视频**
```
用户：[视频] 今天跳舞的视频

AI回应："跳得真好！看得出来动作很熟练。经常跳舞对身体很好，
既锻炼了身体又能结交朋友。不过也要注意劳逸结合，别太累着了。
下次有新舞蹈记得也给我看看！"
```

**示例2：唱歌视频**
```
用户：[视频] K歌房录的歌

AI回应："唱得真不错！声音很好听，感情也很投入。
能听到你开心的歌声，我也很高兴。喜欢唱歌是好事，
既陶冶情操又放松心情。下次唱什么歌呀？"
```

## 视频要求

### 文件限制
- **时长**：最长60秒
- **大小**：最大50MB
- **格式**：MP4, MOV等常见格式

### 建议
- 📱 横屏拍摄效果更好
- 🌞 光线充足拍得更清楚
- 📶 Wi-Fi环境上传更快
- 🎯 添加文字说明AI回应更准确

## 常见问题

### Q1: 视频上传失败怎么办？
**原因：**
- 网络不稳定
- 视频文件太大
- 服务器繁忙

**解决方法：**
1. 检查网络连接（建议使用Wi-Fi）
2. 压缩视频或缩短时长
3. 稍后重试

### Q2: 视频超过50MB怎么办？
**解决方法：**
1. 使用手机自带的视频编辑功能压缩
2. 缩短视频时长
3. 降低视频分辨率（如从1080p改为720p）

### Q3: AI会看视频内容吗？
**当前版本：**
- AI基于您输入的文字说明来回应
- 暂不分析视频画面内容

**未来版本：**
- 将支持AI视频内容理解
- 可以识别活动类型（跳舞、唱歌等）
- 提供更智能的回应

### Q4: 视频会保存在哪里？
- 视频上传到服务器
- 可以在聊天记录中随时观看
- 不会占用手机空间

### Q5: 可以发送几个视频？
**免费用户：**
- 每天5个视频

**付费用户：**
- 每天20个视频

## 使用技巧

### 1. 文字说明要清楚
✅ 好的说明：
- "今天学的新广场舞"
- "公园晨练太极拳"
- "唱的《夕阳红》"

❌ 不好的说明：
- "视频"
- "看看"
- 留空

### 2. 视频内容建议
推荐分享：
- 🕺 广场舞、太极拳等锻炼视频
- 🎤 唱歌、乐器演奏
- 🌳 公园散步、旅游风景
- 🍳 做菜、手工艺
- 👨‍👩‍👧‍👦 家人聚会、孙子孙女

### 3. 最佳拍摄时机
- 上午：光线好，精神佳
- 避免逆光拍摄
- 保持手机稳定
- 声音清晰（唱歌类）

## 后端API说明

### 上传视频接口
```
POST /api/v1/media/upload-video
Authorization: Bearer <token>
Content-Type: multipart/form-data

参数：
- video: 视频文件
- companion_id: 陪伴角色ID

返回：
{
  "success": true,
  "data": {
    "media_id": "abc123",
    "url": "https://cdn.example.com/videos/abc123.mp4",
    "thumbnail": "https://cdn.example.com/thumbs/abc123.jpg",
    "duration": 45,
    "size": 8900000
  }
}
```

### 发送视频消息接口
```
POST /api/v1/conversations/send-video
Authorization: Bearer <token>

参数：
{
  "companion_id": 1,
  "media_id": "abc123",
  "caption": "今天跳舞的视频"
}

返回：
{
  "success": true,
  "data": {
    "conversation_id": 1,
    "user_message": {
      "id": 123,
      "type": "video",
      "content": "今天跳舞的视频",
      "media": {...},
      ...
    },
    "assistant_message": {
      "id": 124,
      "type": "text",
      "content": "跳得真好！...",
      ...
    }
  }
}
```
