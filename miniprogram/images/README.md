# 图片资源说明

## 目录结构

```
images/
├── companion.png          # 底部导航栏 - 陪伴图标（未选中）
├── companion-active.png   # 底部导航栏 - 陪伴图标（选中）
└── ... 其他图标资源
```

## 图标规格

### 底部导航栏图标

- 尺寸：81px * 81px
- 格式：PNG
- 背景：透明
- 颜色：
  - 未选中：#7A7E83
  - 选中：#4A90E2

## 占位说明

目前项目中的图标为占位图标，正式上线前需要替换为设计师提供的正式图标。

## 图标获取

可以从以下资源网站获取图标：

- [iconfont](https://www.iconfont.cn/)
- [iconpark](https://iconpark.oceanengine.com/)
- [Flaticon](https://www.flaticon.com/)

## 注意事项

1. 所有图标需要有透明背景
2. 建议使用SVG格式，小程序会自动转换
3. 图标颜色应与UI设计保持一致
4. 确保图标在不同屏幕密度下都清晰可见
